# Provenance

Written from scratch in November 2026 by Christoph Fellner as a personal project, from public
documentation and open source projects only:

- Keycloak documentation and container images
- Caddy documentation and the caddy-dns/cloudflare module
- Open WebUI documentation (Keycloak and SSO pages)
- University of Oslo: keycloak-psso-extension and weblogin-mac-sso-extension (README,
  wiki and releases)
- Nordeck: jitsi-keycloak-adapter-v2; Jitsi: docker-jitsi-meet and handbook
- Nextcloud: container image and the user_oidc app documentation
- Cloudflare: tunnel and DNS documentation
- Apple: public deployment documentation and the public device-management schema
  (github.com/apple/device-management)
- IETF: RFC 8693 (token exchange), RFC 8628 (device authorization), RFC 7636 (PKCE),
  draft-ietf-wimse-aims
- IDE vendor documentation: Apple Xcode, Microsoft Visual Studio and VS Code, Qt, JetBrains

It contains no code, configuration, documents, customer information or other material
taken from any employer, past or present, and was not derived from any earlier internal
prototype. Where an upstream project's licence or documentation is relevant, it is cited in
the file that uses it.

The University of Oslo Keycloak extension is licensed GPL-2.0-or-later. It is deliberately
not copied, vendored or modified here; SLATFF.Cloud only documents how to obtain and configure it.
